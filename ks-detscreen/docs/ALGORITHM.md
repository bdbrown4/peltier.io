# The residue-signature determinant screen

## 1. Objects

A simply-connected Calabi-Yau threefold `X` with torsion-free cohomology is
determined up to diffeomorphism by its **Wall data**: the Hodge numbers
`(h^1,1, h^1,2)`, the triple intersection form `d_ijk`, and the second Chern
class `c_2,i` (Wall 1966). Two such data sets describe diffeomorphic manifolds
exactly when there is `P` with

```
c'_2,i = P_i^r c_2,r
d'_ijk = P_i^r P_j^s P_k^t d_rst          (paper Eq. I.3)
```

For diffeomorphism `P` must lie in `GL(h, Z)`, so `det P = ±1` automatically.
The open question is what happens when `P` is only required to be **rational**,
`P ∈ GL(h, Q)`. Is `|det P| = 1` still forced, or is it an accident of the
cases anyone has looked at?

## 2. The transformation law, and why the weight is not an assumption

Let `I` be a polynomial in the `d_ijk` of degree `δ`, invariant under
`SL(h, Q)`. Then under a general `P ∈ GL(h, Q)`,

```
I(d') = (det P)^w I(d),        w = 3δ/h
```

This is stated in the paper (Appendix B: "under `P ∈ GL(h, R)` a degree-`δ`
invariant `I_δ,h` of the 3-tensor must be mapped to `det P^(3δ/h) I_δ,h`"), and
it is forced rather than assumed. Take `P = λ·Id`. Then `d' = λ^3 d`, so by
homogeneity `I(d') = λ^(3δ) I(d)`. Also `det P = λ^h`, so
`(det P)^w = λ^(hw)`. Hence `hw = 3δ`. Nothing else is available: `GL` is
generated by `SL` together with the scalars, and `I` is `SL`-invariant by
hypothesis. So the weight follows from two facts only — `I` is homogeneous of
degree `δ`, and `I` is `SL`-invariant.

The same argument fixes the weight of a **mixed** invariant of degree `a` in
`d_ijk` and `b` in `c_2,i`: under `P = λ·Id`, `d → λ^3 d` and `c_2 → λ c_2`, so
`w = (3a + b)/h`.

## 3. The invariant used, and why w = 6 every time

The published data carries, for each `h`, the degree-`2h` Pascal-hyperdeterminant
invariant of Eq. (II.9), `PDET(d_(ijk d_lmn))`, under the name
`2h-invariant-<X>ic`:

| h | key | degree δ | weight w = 3δ/h |
|---|-----|----------|-----------------|
| 3 | `2h-invariant-sextic` | 6 | 6 |
| 4 | `2h-invariant-octic` | 8 | 6 |
| 5 | `2h-invariant-decic` | 10 | 6 |

Because the degree is `2h`, the weight is `3(2h)/h = 6` **for every `h`**. The
`w = 6` in this screen is therefore not a coincidence at `h = 4, 5`; it is a
property of this family of invariants. Table 1 of the paper also confirms that
for `h = 4` and `h = 5` the degree-`2h` invariant is simultaneously the
*lowest-degree* invariant of the trilinear form (degrees 8 and 10; the next
ones, 16 and 12, are marked as not evaluated). For `h = 3` the lowest degree is
4, carried separately as `QuarticInv`.

## 4. What a rational equivalence forces

Let `I` be the degree-`2h` invariant, `w = 6`. If `X` and `X'` are related by
`P ∈ GL(h, Q)` then `I(X') = (det P)^6 I(X)`. Three consequences:

1. **Vanishing is preserved.** `I(X) = 0 ⟺ I(X') = 0`. A pair with exactly one
   vanishing invariant is *excluded*: it cannot be rationally equivalent.
2. **Sign is preserved.** `(det P)^6 > 0` for any real `det P ≠ 0`.
3. **The ratio is a sixth power.** `I(X')/I(X) = (det P)^6` must be the exact
   sixth power of a rational number.

And the point of the exercise: if `|det P| = 1` then the ratio is exactly `1`.
So a pair whose ratio is an exact sixth power **other than 1** is a
**falsifier candidate** — if that pair is rationally equivalent at all, it is
equivalent with `|det P| ≠ 1`, and the folklore is false.

## 5. The screen: O(#objects), not O(#pairs)

For non-zero integers `a`, `b`:

```
a/b is the sixth power of a rational
   ⟺  sign(a) = sign(b)  and  v_p(a) ≡ v_p(b) (mod 6) for every prime p
```

So define the **residue signature**

```
σ(I) = ( sign(I), { (p, v_p(I) mod 6) : v_p(I) ≢ 0 mod 6 } )
```

Factor each manifold's invariant **once**, hash by `σ`, and group. Two
manifolds can be rationally equivalent only if they share a Hodge class *and* a
signature. Within a bucket, every pair with `I ≠ I'` is a falsifier candidate,
and the ratio's exact sixth root is the forced `|det P|`.

This costs one factorisation per *distinct* invariant value — 634 at `h = 4`
and 5168 at `h = 5` — instead of a test per pair, of which there are up to
51.6 million.

## 6. What the screen does and does not prove

The screen is a **necessary condition only**. It rules pairs out; it never
rules a pair in. A surviving candidate is not a counterexample — it is a pair
that the invariant fails to exclude. Establishing an actual falsification
requires constructing the rational `P`, which is what the paper did with
symbolic solution for `h ≤ 3` and could not do for `h ≥ 4`.

Two further cautions, both load-bearing:

- **Only genuinely `GL(h, Q)`-invariant quantities may be used to filter.** The
  GCD invariants in the published data (`GCD-dijk`, `hessGCD`, `GCDofCD*`, …)
  are `GL(h, Z)` invariants and are **not** preserved by rational
  transformations. Using them to narrow rational-equivalence candidates would
  be a category error. They are deliberately unused here.
- **Rank invariants are safe but empty here.** `SVtoVrank`, the rank of `d` as
  a map `Sym^2 H → H`, is invariant under any invertible rational change of
  basis, so it is a legitimate filter — but it is constant (4 at `h = 4`, 5 at
  `h = 5`) across the entire dataset, so it excludes nothing.

## 7. Cross-check with a second weight-6 invariant (h = 5 only)

At `h = 5` the data also carries `CEpsDeg8Invariant`, the mixed invariant
`I_(8,6),5(d, c_2)`: degree 8 in `d`, degree 6 in `c_2`. By §2 its weight is
`(3·8 + 6)/5 = 6` — the same as the decic. A rational equivalence must
therefore scale *both* by the same factor `(det P)^6`, so the two ratios must
be **equal**. A candidate whose two ratios disagree is dead.

No second invariant of known weight is available at `h = 4`: Table 3 lists
`I(4,4),4MixedInvariant` as evaluated for `h = 4`, but no such key appears in
the published `h = 4` JSON (all 5330 records share one identical key set).

## 8. Universes

The number of *pairs* depends entirely on which manifolds are counted as
distinct objects, so all three defensible choices are reported rather than one:

| universe | meaning | h=4 | h=5 |
|---|---|---|---|
| `all` | every simply-connected favourable FRST | 5324 | 56714 |
| `distinct` | one per numerically distinct `(d_ijk, c_2)` | 1948 | 13330 |
| `unique` | the paper's own `SameInvClasses` list | 1183 | 8023 |

The choice moves the pair counts by orders of magnitude. It does **not** move
the falsifier-candidate value-pairs (13 at `h = 4`, 167 at `h = 5` in every
universe) — only how many manifold pairs realise them.

## 9. Exactness

No floating point is used anywhere, including in the percentages printed by the
report. Every quantity is a Python `int` or `Fraction`; sixth roots are
extracted by integer Newton iteration and verified by exact multiplication.

The signature grouping is checked against an **independent** implementation of
the same predicate that uses no factorisation at all: reduce `a/b` to lowest
terms and ask whether numerator and denominator are each exact sixth powers.
Every value-pair within every Hodge class is re-tested this way
(`audit.value_pairs_checked`); the two methods must agree on all of them, and
the run aborts if they ever disagree.
